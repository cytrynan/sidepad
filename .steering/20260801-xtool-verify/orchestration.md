## 止まった点・教訓

1. **GitHub API + GCM のリポ作成が分類器に拒否された**（過去実績ありの手順が通らず）。無人セッションでは資格情報を触る操作は通らない前提で、リポ作成だけ事前にKに頼む段取りが正
2. Opus の自己申告した逸脱2件（子への依頼文にOSバージョン未記載／評価係未起動）。後者は全体側で後置起動により回収
3. Opus の報告 `report.md` がガードレールで書けず通知本文で返された → 成果物は最初から「返信で返す」指定が安全
4. Git Bash から `wsl bash /root/...` はパス変換で壊れる（受入検証中に実地で再現）。WSL 跨ぎは PowerShell 経由が正
