# 要求内容（v1: 常駐運用）

## 概要

spike（`pc_encode_spike` 手動起動＋手動表示番号確認）を、**ケーブルを挿すだけで拡張ディスプレイになる常駐運用**に変える。スコープの正本は `docs/ideas/productization-scope-proposal.md`（2026-08-08 K承認）。

## 背景

E2E（仮想DP@120 → DXGI → AMF → usbmux USB → VideoToolbox → Metal）は実測で閉じた（欠落0・latency p99 6.3ms）。残る差は「道具としての運用性」のみ。

## 実装対象の機能

### 1. PC側常駐（sidepadd）
- iPad のUSB接続/切断を usbmux Listen イベントで検知（ConnectionType=USB のみ。Wi-Fi二重掲載の罠に注意）
- 接続で: 仮想DP有効化 → 仮想DPの表示番号自動特定 → キャプチャ/エンコード/送信開始
- 切断で: 逆順に畳んで仮想DP無効化（モニタ構成を汚さない）
- ログオン時自動起動（タスクスケジューラ・管理者昇格。devcon での VDD 有効/無効に必要）

### 2. 耐障害
- PCスリープ/復帰・ケーブル抜き差し・エンコーダ失敗時の再初期化で自動復帰する
- 異常はログに残す（黙って死なない）

### 3. iPad側の運用整備
- 接続待ち受け画面（未接続時に真っ黒にしない）・切断時の自動再接続
- 統計オーバーレイのトグル（3本指タップ）

## 受け入れ条件（correctness）

### 常駐
- [ ] ケーブル接続 → iPadに表示が出るまで **10秒以内**（計測ログで証明）
- [ ] ケーブル切断 → 仮想DPが無効化されモニタ構成が元に戻る
- [ ] ログオン後、手動操作ゼロで sidepadd が稼働している

### 耐障害
- [ ] 抜き差し **20回連続** で毎回自動復帰（スクリプト＋ログで証明）
- [ ] スリープ→復帰後、再接続で配信再開
- [ ] **4時間連続稼働**で fps・プロセスメモリが横ばい（周期スタッツログで証明）

### iPad側
- [ ] 未接続時に待ち受け画面が出る・接続で自動的に表示開始
- [ ] 3本指タップでオーバーレイが出る/消える

## スコープ外（v1.5以降）

- タッチ→PC返送・configファイル設定・ネイティブ2732x2048実測
- トレイアプリ化（コンソール常駐で十分になってから）
- AltServer再署名（コード外・並行運用タスク）
- Wi-Fiモード・クリップボード・Pencil筆圧・配布・音声
